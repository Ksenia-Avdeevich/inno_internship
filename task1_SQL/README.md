# SQL-задания по демонстрационной базе данных [Pagila](https://github.com/devrimgunduz/pagila)

## Описание

Решение 7 SQL-запросов на основе демонстрационной базы данных **Pagila** (PostgreSQL).
Все запросы находятся в одном файле: **`queries.sql`**

## Список запросов

1. **Количество фильмов в каждой категории** — сортировка по убыванию.
2. **Топ-10 актёров** по количеству аренд их фильмов — сортировка по убыванию.
3. **Категория фильмов**, на которую потрачено больше всего денег.
4. **Фильмы, отсутствующие в inventory** — без использования оператора `IN`.
5. **Топ-3 актёра** по количеству появлений в фильмах категории «Children» (с учётом совпадений).
6. **Города с количеством активных и неактивных клиентов** — сортировка по числу неактивных.
7. **Категория с наибольшим количеством часов аренды**:
   - для города, название которого начинается на «A»;
   - для городов, в названии которых есть дефис («-»).
